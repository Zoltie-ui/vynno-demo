# Vynno 智储 · 可运行网页原型

依据用户提供方案第7–10页的定位、四项智能体功能和储蓄交互流程实现。

## 启动

需要 Python 3.9 或以上，无需安装第三方依赖。Windows 双击「启动Vynno.cmd」，然后访问 http://127.0.0.1:8765 。也可以在当前目录运行 `python server.py`。关闭命令窗口即可停止服务。

## 一次完整体验

1. 点击右下角 Vynno 财务搭子，输入「我想90天存3000元去旅行」。
2. 在目标草稿中补充名称、单次上限50元和月度总预算1200元。
3. 点击「检查计划」，确认计算结果后点击「确认创建目标」。
4. 打开今日盲盒，点击「确认完成模拟储蓄」。页面进度与收藏会同步变化。
5. 进入数字藏品馆，点击徽章翻转查看本地编号；刷新页面后数据保留。

## 当前能力

- 自然语言提取明确的目标金额与期限，填写表单草稿。
- 计算预算可行性，检查多个目标的月需求合计，给出延长期限建议。
- 随机储蓄任务受剩余目标、单次上限和月度剩余预算约束；待完成任务预占预算。每日每目标最多完成或跳过一个任务，任务24小时过期。
- 模拟完成任务与防止重复记账；暂停/恢复目标；按实际记录展示进度。
- 每次任务提供免费纪念徽章，目标达成时标记里程碑。徽章为本地生成，未调用AIGC，未上链。
- 财务陪伴、消费取舍、储蓄压力等本地规则回复；可选接入支持 Chat Completions 的大模型。
- 浏览器本地保存、导出和清空数据，支持手机尺寸。

## 可选：接入真实大模型

在启动服务的同一个 PowerShell 窗口设置环境变量：

```powershell
$env:VYNNO_API_KEY='填入你自己的密钥'
$env:VYNNO_API_BASE='https://api.openai.com/v1'
$env:VYNNO_MODEL='gpt-4.1-mini'
python server.py
```

模型名称应改为服务商当前允许使用的模型。密钥仅由服务端读取，不发送给浏览器。支持同一接口协议的其他服务商；不要把密钥提交到代码仓库。明确金额的目标草稿由本地规则优先生成，开放式对话由模型完成。网页传给模型的是最近对话和目标摘要，接入前请了解服务商的数据处理方式。

## 智能体与数据设计

`server.py` 包含计划工具 `/api/plan`、任务工具 `/api/task`、对话入口 `/api/chat` 以及财务陪伴系统提示词 `SYSTEM`。预算计算采用整数分和 Decimal，避免金额浮点误差。网页中的操作由用户确认，不让语言模型直接执行资金操作。

`public/app.js` 管理浏览器状态，分别存储目标、任务、模拟记录、收藏和对话。月度预算为整个账户共享的日历月预算；计划可行性使用每30天折算估计，实际任务还受日历月余额限制，因此不保证按期完成。暂停不会冻结原目标期限，恢复时重新检查剩余时间。期限按创建时间起算的自然日计算。

## 演示范围与后续接入

此版本是本地单人产品原型。没有真实资金、存款收益、银行开户、支付、身份核验、上链、后台消息推送、在线社交和AIGC图片生成。没有训练模型或实现强化学习。用户提供的方案中的市场数据和盈利测算未作为已验证事实写入产品。

生产版本需接入身份认证、数据库、服务端账本和幂等交易、银行授权接口、通知服务，并审查金融业务与数据使用要求。当前本地记录可以被浏览器用户修改，不能作为真实账本；只监听本机地址，请勿将其直接暴露到公网。使用虚构信息演示即可。
